Thanks for installing SkullClick!

Pin the skull icon to your toolbar, open any page and click the icon (or press the shortcut below). Then click the element you want gone.

How to use

Alt+Shift+K or the toolbar icon
Start / stop picking
Click
Remove the highlighted element
Shift + Click
Remove and keep picking
↑ ↓
Select the parent / back to the child element
Enter
Remove the selected element
Ctrl + Z
Undo the last removal
Esc
Stop picking

Removed elements come back when the page reloads — unless Grudge mode is on.

Firefox: open about:addons, click the gear icon and choose “Manage Extension Shortcuts”.

Grudge mode: remember removed elements

SkullClick remembers every element you remove and hides it automatically on your next visits to the same page.

Needs access to all websites so it can run on page load. The list is stored only in this browser and is never sent anywhere.

Grudge mode is on, but SkullClick has no access to websites, so it can't hide anything.
